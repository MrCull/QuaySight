# Owner-code list is unchecked (ticket #43)

Noted: 16 October 2026. Nothing was checked in this note.

`src/domain/ownerCodes.ts` holds about 200 container owner codes (three letters plus U) that the owner-code
question offers the model. The list was written from memory. It was not copied from, and has not been compared
with, the BIC owner-code register or any other source. Some codes may be wrong, and real ones are missing.

## What to do

- Check each code against the BIC register (the register's own pages; no source is recorded here yet) and record
  the source and check date in this note.
- Remove codes that are not on the register and add the common ones that are missing.

## Why it is not urgent

A code missing from the list costs one letter-by-letter reading, not a wrong answer: "none of these" is always
offered, and the letters still stand. A wrong code on the list could pull a reading towards an owner that does not
exist, so the list should be checked before its picks are relied on.
